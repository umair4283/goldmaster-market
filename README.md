# NovaFX — Forex & IB Portal Prototype

Original brokerage/IB portal prototype. This is NOT affiliated with QberFX.

## Included
- Responsive landing page
- Client registration with referral code
- Login demo
- Client dashboard
- KYC status UI
- MT5 account UI (demo data)
- Deposit/withdrawal request UI
- IB referral/commission dashboard
- Admin dashboard mockup
- Clear separation between demo UI and live integrations

## Production integrations required
1. Licensed/authorized broker relationship
2. MT5 Manager/API or approved bridge
3. Payment provider APIs
4. KYC/AML provider
5. Transactional email/SMS provider
6. Secure production database
7. Authentication/session management
8. Legal documents and jurisdiction-specific compliance review

Do not represent demo balances, trades, licences, registrations, or payment transactions as real until connected and independently verified.
